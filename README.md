## Стек технологий

- React
- JavaScript
- CSS Modules
- Vite

## Архитектура

- Компонентный подход
- Все медиазапросы описаны внутри компонентов
- Используются CSS-переменные для цветов и шрифтов.
- Используются алиасы импортов (`@/components`, `@/context` и т.д.)

## Функциональность

- Фильтрация каталога с помощью готовых фильтров и поиску.
- Адаптивная верстка (desktop / tablet / mobile)

## 📂 Структура проекта

src/

- components/ — UI-компоненты
- pages/ — страницы приложения
- data/ — временные данные
- assets/ — изображения и иконки

## Установка и запуск

```bash
npm install
npm run dev
```
